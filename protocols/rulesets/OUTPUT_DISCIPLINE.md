# Output discipline ruleset

## Skimmability

- Keep outputs skimmable and structured.
- Prefer consistent status tags: `[OK]`, `[!]`, `[X]`.

## Avoid huge dumps

- Avoid huge logs/diffs; summarize and point to file paths/commands.
- If you must include output, include only the minimal excerpt.

## Consistency

- Use the same headers/format across checkpoints so humans can scan quickly.
