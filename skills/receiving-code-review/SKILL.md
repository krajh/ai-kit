# Receiving Code Review

## Process

1. **Restate and verify** the feedback in your own words.
2. **Clarify** any ambiguous items before changing code (one question at a time).
3. **Implement one item at a time** with focused changes.
4. **Verify** each change with relevant checks.
5. **Run `verify-loop`** before claiming completion.

## Disagreement

If you disagree:

- Explain clearly with technical reasoning
- Offer an alternative if possible

## Output Discipline

- Keep updates concise
- Report what changed and how it was verified
- Use status tags: `[OK]`, `[!]`, `[X]`
- Include command + result when reporting verification
